## 🛡️ Flagship — Armur.ai

> **Pentest Swarm AI** — an AI swarm that doesn't just *find* vulnerabilities, it **chains them, exploits them, and writes self-verifying proof-of-concepts** against the live target. Findings are proven by non-LLM oracles (out-of-band callbacks, timing, differential response), so what you get is **verified, not hallucinated**. Runs fully local / air-gapped with a bring-your-own model, ships with one-command vulnerable labs, and streams the whole attack — chains, exploit proof, attack graph — to a live dashboard.
